# ThreadSanitizer suppressions for the abyss test binaries.
#
# Entries match any frame in the race's stack, so a broad pattern silences
# genuine races in our own code whenever the stack passes through the named
# code. Every entry must name the specific construct TSAN cannot reason about
# and say why the access is safe.
#
# Dependencies are built instrumented (cmake/triplets/*-linux-tsan.cmake), so a
# report inside RocksDB or any other dependency is either a real race or needs
# its own justified entry here. Do not reintroduce library-wide patterns such as
# race:rocksdb:: -- they existed only to paper over the uninstrumented build.
